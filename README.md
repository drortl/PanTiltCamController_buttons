# PanTiltCam - Android app

Download the Android app for the PanTiltCam controller:

**[Download PanTiltCam.apk](https://github.com/drortl/PanTiltCamController_buttons/releases/latest/download/PanTiltCam.apk)**
(always the newest version)

## Install
1. Open the downloaded file **PanTiltCam.apk**.
2. If Android asks, allow **Install unknown apps** for your browser or Files app.
3. Tap **Install**, then open **PanTiltCam** and allow **Nearby devices** (Bluetooth).

The quick guide is inside the app: tap **?** at the top.
